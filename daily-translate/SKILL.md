# Daily Translate（中英互译入库）

## Overview

将用户给出的单词或句子做**中英互译**（自动判断输入语言），按类型归类写入英语学习知识库（词根学习法），并重新构建前端打包文件。知识库路径由本 skill 目录下的 `config.json` 管理（见下方步骤 0），不硬编码。

## 步骤 0：知识库路径管理（每次调用最先执行）

1. 读取本 skill 目录下的 `config.json`（与 SKILL.md 同目录），取 `library_path`。
2. **路径校验**：目录存在，且其下包含 `generate-content.js` 和 `content/` 子目录（证明是完整知识库）。
3. 分支处理：
   - ✅ **校验通过** → 直接使用该路径继续后续步骤。
   - ⚠️ **config.json 不存在或 library_path 为空**（首次使用）→ 引导用户：询问想用哪个文件夹存放学习产生的文件（建议默认 `~/workspace/english-learn`）。若用户指定的是已有完整知识库，直接写入 config.json；若是空文件夹，提示需要先初始化知识库或从旧位置迁移文件，迁移/初始化完成后再写入 config.json。
   - ❌ **路径失效**（目录不存在或缺少关键文件）→ 告知用户"知识库路径失效，可能被移动或删除"，请用户指定新位置（或确认恢复原路径）。用户确认后**更新 config.json**，再继续后续步骤。禁止在未确认前静默使用失效路径或新建文件到错误位置。

## 工作流（步骤 0 校验通过后）

1. **判断输入语言**：
   - **中文输入** → 翻译成地道英文
   - **英文输入** → 翻译成地道中文
2. **翻译**：直接给出地道翻译。口语优先，给出 1 个主翻译 + 必要时 1 个变体，并简短讲解关键用词（发音/搭配/语境差异），每条讲解不超过一句话。
3. **归类入库**：先读取本 skill 的 `references/library-schema.md` 了解知识库结构，再按内容类型处理：
   - **单词**（如 "responsibility 怎么翻译"）→ 按 schema 中的「单词条目格式」追加到 `content/<首字母>.md`。
   - **句子 / 日常用语** → 按 schema 中的「日常用语格式」追加到 `content/phrases.md`（匹配场景分组，无则新建）。
4. **构建**：按 schema 中的「构建命令」在知识库根目录运行 `node generate-content.js`。
5. **告知**：提示用户刷新浏览器即可查看新内容。

## 注意事项

- **先读后写**：编辑任何 .md 文件前，必须先 Read 该文件（Edit 工具要求），且保持原文件格式风格。
- **文件路径**：所有入库和构建操作都基于 config.json 的 `library_path`，使用绝对路径；禁止硬编码知识库路径。
- **结构单一来源**：知识库结构约定只存在于 `references/library-schema.md`，入库格式、分组列表、构建命令的变更只改该文件。
- **不打扰**：若用户明确说"只要翻译，别入库"，则跳过入库和构建步骤（翻译本身不依赖知识库，可跳过 schema 读取）。
- **语感优先**：翻译追求地道自然（如 head out 比 go out 更口语），避免逐字直译。
